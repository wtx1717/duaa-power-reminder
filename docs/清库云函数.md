# 清库云函数

`cloudfunctions/clearDatabase/` 提供一个仅用于人工操作的破坏性维护函数。它会删除项目维护的每个集合中的全部文档，但不会删除集合本身或集合索引。

## 覆盖的集合

- `user_configs`
- `user_query_state`
- `meters`
- `power_records`
- `notification_records`
- `meter_check_jobs`
- `job_locks`
- `ops_dashboard_snapshots`

新增数据库集合后，需要同时修改 `cloudfunctions/clearDatabase/index.js` 中的 `COLLECTIONS`，否则新集合不会被清空。

## 手动调用

1. 在微信开发者工具中上传并部署 `clearDatabase`，选择“云端安装依赖”。
2. 打开云开发控制台的云函数列表，选择 `clearDatabase` 的“测试”或“调用”。
3. 在云函数环境变量中配置 `CLEAR_DATABASE_CONFIRMATION`，值应为随机且足够长的字符串；不要把它提交到代码仓库。
4. 手动传入以下事件参数（`confirm` 的值替换为上一步配置的密钥）：

```json
{
  "confirm": "这里填写 CLEAR_DATABASE_CONFIRMATION 的值"
}
```

未配置环境变量时函数只返回 `server_configuration_required`；确认值不匹配时只返回 `confirmation_required`，这两种情况都不会删除任何数据。

## 注意事项

- 该目录没有 `config.json`，不会创建定时触发器；不要把它配置到任何定时任务中。
- 清理前应先导出或备份需要保留的数据，并暂停 `scheduledCheck`、`scheduledCheckDispatch` 等可能写入数据库的定时任务。
- 云函数调用权限仍应在云开发控制台限制为管理员或可信运维账号；“手动调用”不是权限控制。
- 函数按集合顺序删除。如果中途失败，会返回 `partial_failure` 及已处理的集合，需要人工确认剩余数据后再执行一次。
